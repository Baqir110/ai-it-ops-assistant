# Backup Failure

## Symptoms
- Backup job failed
- Missing recent backups
- Data loss risk

## Evidence to Collect
- Backup job logs
- Storage capacity
- Network connectivity
- Last successful backup

## Diagnosis
1. Check backup job logs
2. Verify storage capacity
3. Check network connectivity
4. Identify failure cause

## Safe Actions
- Review backup logs
- Check storage capacity
- Verify network

## Risky Actions
- Retry backup (LOW risk)

## Rollback Instructions
- If retry fails, investigate root cause
- Consider manual backup

## Verification Steps
- Backup completes successfully
- Backup file is valid
- Backup size is reasonable
